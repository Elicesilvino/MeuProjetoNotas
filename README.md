\# 📚 Projeto de Gerenciamento de Notas em C#



Este é o meu primeiro projeto em \*\*C# / .NET\*\*, desenvolvido para praticar conceitos fundamentais de desenvolvimento Back-End.



\## 🚀 Conceitos Praticados



\- \*\*Arrays (Vetores):\*\* Armazenamento de tamanho fixo para as notas das provas principais.

\- \*\*List<T> (Listas Dinâmicas):\*\* Estrutura flexível para adicionar notas extras de trabalhos.

\- \*\*Funções (Métodos):\*\* Organização do código e cálculo da nota final acumulada.

\- \*\*Git \& GitHub:\*\* Controle de versão e publicação do projeto na nuvem.
